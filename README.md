# Final-project-code

## Introduction

This repository contains the MATLAB code used for the final-year project: **Optimisation-based battery control for a UK household-scale PV–wind–battery system under time-varying electricity tariffs**.

The software simulates and compares three energy management strategies for a household-scale PV–wind–battery system: day-ahead mixed-integer linear programming (MILP), rolling-horizon model predictive control (MPC), and a rule-based baseline. The purpose of the code is to evaluate how different control strategies affect daily electricity cost, battery scheduling behaviour, grid import/export power and renewable energy utilisation under seasonal scenario random sampling.

## Contextual overview

The model represents a grid-connected household energy system consisting of:

- household electricity demand;
- photovoltaic (PV) generation;
- wind generation;
- battery energy storage system (BESS);
- electricity import/export from the grid;
- half-hourly time-varying import and export tariffs.

The general workflow is:

1. Load household demand, PV generation, wind generation and tariff datasets.
2. Convert all input data to a common half-hourly resolution.
3. Generate synthetic daily scenarios for spring, summer, autumn and winter using slot-wise random sampling.
4. Apply the same input profiles to the day-ahead MILP, rolling-horizon MPC and rule-based baseline strategies.
5. Compare the strategies in terms of daily electricity cost, cost saving, battery charging/discharging power, state of charge and grid import/export power.
6. Generate summary tables and figures for the final report.

## Files in this repository

The repository includes the following files:

- `EMS_strategy_comparison_all_seasons.m`  
  Main MATLAB script. This script reads the input datasets, runs the three EMS strategies across all seasons, generates summary tables and produces the main result figures.

- `LCL-June2015v2_0.xlsx`  
  Household electricity demand dataset from the Low Carbon London dataset.

- `ninja.xlsx`  
  PV generation profile used in the simulation.

- `ninja_wind_51.3228_-0.1038_corrected.xlsx`  
  Wind generation profile used in the simulation.

- `agile-half-hour-actual-rates-01-01-2024_31-12-2024.xlsx`  
  Half-hourly import and export electricity tariff data.

- `Code in Command window.txt`  
  Additional MATLAB commands used to generate the final Chapter 4 profile figures. These commands should be entered in the MATLAB Command Window after the main script `EMS_strategy_comparison_all_seasons.m` has been run successfully, because they require the variables generated by the main script.

## Installation instructions

The code was developed and tested in MATLAB. To run the software, the following software and toolboxes are required:

- MATLAB;
- YALMIP optimisation toolbox;
- IBM ILOG CPLEX Optimizer;
- Microsoft Excel-compatible input files.

Before running the code, YALMIP and CPLEX should be installed and added to the MATLAB path. The CPLEX solver must also be correctly linked to MATLAB so that YALMIP can call it when solving the MILP optimisation problems.

All input data files should be placed in the same folder as the main MATLAB script.

## How to run the software

To run the main simulation:

1. Download or clone this repository.
2. Open MATLAB.
3. Set the current MATLAB folder to the repository folder.
4. Make sure the required Excel input files are in the same folder as `EMS_strategy_comparison_all_seasons.m`.
